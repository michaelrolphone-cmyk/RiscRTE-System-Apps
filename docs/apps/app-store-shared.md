`96be42d15b8edfaaafadb90304ab7da540351636`. `SOURCE-BASE.json` records exact

## Preserved authority boundaries

- Default Check is the original release-bank catalog. Merely finding a native
  package-feed suffix does not change that source. Selected X4 App Store 1.5.1
  had installed/staged actions, not the separately gated 1.6.0 feed UI.
- Installed/staged rows use the optional installed-apps contract. A copied
  selection binds catalog generation, id, version and complete route. Storage
  volume is acquired only for confirmed mutations. Staged descriptor paths
  are never executable launch authority. Settings remain provider-owned.
- Wi-Fi policy and saved credentials retain their original namespace 1 and 6
  encodings. Check is explicit, connection is bounded to 30 seconds, foreign
  already-active Wi-Fi is not disconnected, and credentials are never written.
- Cancel is processed before update progress. Radio cleanup precedes activation;
  activation uncertainty requires restart rather than invented success or exit.
- Scene documents contain intent/data only. Shared resident controls own
  presentation, input and physical policy. Cleanup uncertainty pins custody.

storage and workflow effects; all selected products include BLE broadcast.
