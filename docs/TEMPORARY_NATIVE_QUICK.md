# Temporary native app-local Quick

This explicit composition restores a local Quick sheet to a selected native
Springboard. It is **not** the established single resident-host overlay
architecture, and does not complete universal Quick availability. Historical
profiles, Home's own Quick controller and direct native Timecard are unchanged
when the new selector is absent.

Select `--quick-actions --native-copied-quick` with the existing Watch native-time,
alarm and sliced-frame selections. The helper stages the exact selected Runtime
copied preference SDK, adds `storage.preferences` API 1 instance 1, and records
`native_copied_quick` ownership, SDK hashes and pending-frame contract. Existing
KV namespace 1, readonly native realtime, battery and alarm services remain.
Wi-Fi is the established Setup launch to `wifi_settings.elf`; no radio-control
grant or synthetic radio toggle is introduced.

## Presentation and input ownership

`PORTABLE_QUICK_SLICED_NATIVE` keeps app requested/completed frame identities
separate from all-presentation identities. A modal image or restored underlay
cannot publish a new app hit map. Immutable native Quick rendering copies the
controller state and time string, replays all physical rows and preserves exact
RGB565 pixels. A copied preference mutation must observe completion of its exact
pending preview; idle after a discarded/replaced frame is not sufficient.

Back, fresh contact, malformed touch, alarm or navigation cancellation is serviced
while waiting. Real retained/fault outcomes stop callbacks. The existing underlay
allocation remains checked: refusal cancels opening and leaves the foreground
usable, with no half-open modal. At 466, that underlay is 434,312 bytes, in addition
to existing replay/display/alarm allocations; this does not establish device RAM
admission or physical performance.

## Owning qualification

`test_quick_sliced_pending.py` exercises the actual adapter and asynchronous
presentation media: synchronous/late completion, Back/contact/malformed cancel,
discarded and unrelated receipts, display failure, ID exhaustion, immutable
state/full-pixel parity, allocation refusal, full modal close/restore and Wi-Fi
Setup. Media are deterministic doubles, not Runtime or hardware. Existing direct
pending-input and pure pending-helper tests preserve selector-off contracts.
Native Quick raster tests retain historical and native geometry parity.

Product target admission, actual installed launcher interaction, copied preference
write/shared Settings visibility, alarm/Light restoration and physical usability
remain integrator/device gates. Passing owning tests alone is not a release.
