# Springboard reference header

The paper header uses the supplied HTML layout: Orbitron 900 APPS at 30 px, 4 px tracking, x=32 and baseline 58; Orbitron 700 clock at 30 px, right aligned at x=448 on the same baseline; a 4 px rule centered on y=80. The separate battery indicator is removed. Existing 12/24-hour preferences and unpadded hours are preserved.

The licensed reference font files are reused directly and the generated monochrome subset records their hashes. Browser antialiasing differs from the one-bit target raster; no pixel-identical full-screen claim is made. The existing 3 by 4 grid, horizontal page motion, app icons, selection, physical navigation and launch code are unchanged by this focused header change. Home's battery presentation is separate.

Qualification uses actual production Springboard/adapter clock-only scenes: 12/24-hour, midnight, noon, single-digit hours and unavailable time, normal and ASan/UBSan. These scenes have zero app launches. The image checks verify stable title placement, an empty middle header field, right margin and divider geometry. This does not rerun or establish the separate intermittent launch investigation.
