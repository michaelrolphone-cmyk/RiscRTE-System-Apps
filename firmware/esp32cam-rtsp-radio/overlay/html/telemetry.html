Scanning, output and range settings

Changes take effect without restarting the camera. UDP output is enabled by entering the receiver computer's IPv4 address. An empty address disables UDP; this page and the JSON API remain available.

RSSI ranges are estimates. Default reference values are assumptions, and walls, antenna orientation and transmitter power can change the result substantially. iBeacon advertisements can supply their own one-meter reference. Advertised TX power is shown separately.
