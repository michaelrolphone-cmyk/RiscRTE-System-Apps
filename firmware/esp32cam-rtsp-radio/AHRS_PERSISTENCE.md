# Persistent AHRS world orientation

The sensor worker stores a versioned, CRC-protected NVS blob in `rover-ahrs/cal-v1`. It preserves the previous valid record on rejected configuration and verifies each write by reading it back. The original world survey and sonar baseline are never modified. Gyro-bias calibration saves its result without resetting orientation. Bias survives IMU reconnect and ESP32 reboot.

Authenticated `GET /api/ahrs/calibration` reports the saved profile, revision, persistence, restoration and storage errors. `POST` queues a worker-owned flash update and returns202; wait for a new stored revision before treating it as durable. Schema: `rover.ahrs.calibration/1`. Fields: `gyro_bias_rad_s`, `mag_bias_uT`, `mag_correction` (3x3), `mag_calibrated`, `world_id`, `reference_id`, `north_accel_m_s2`, `north_magnetic_uT` (AK8963 native axes), and `world_imu_rotation` (3x3 proper rotation). Unknown fields, non-finite values, singular corrections and improper world rotations are rejected. World reference fields describe an explicitly observed north-facing pose; do not capture a moved pose as the original baseline.

Gravity and magnetic TRIAD at the recorded reference define a boot-independent alignment to the saved IMU-to-world mounting transform. Runtime gyro/gravity attitude provides immediate motion; tilt-compensated magnetic observation corrects heading. AK8963 axes map to MPU axes as(y,x,-z). Reboot recovery initializes from current measurements, not the last stored yaw, so motion while powered off is represented. Magnetic magnitude/vertical degeneracy checks reject unusable field observations. During a magnetic gap, the already aligned gyro attitude coasts; after an IMU generation reset, alignment remains invalid until a new usable magnetic sample arrives.

Telemetry adds `world_alignment_valid`, `world_id`, `world_reference_id`, `world_reference_persistent`, `world_rotation_enu_imu`, `magnetic_heading_age_ms` and `heading_quality`. Existing boot-relative attitude, capture clock/history, sensor ranges and all sensor wiring are preserved. The GUI consumes the world rotation through the original IMU-to-body mounting transform and holds its last world orientation through recovery gaps.

Magnetic hard/soft-iron correction accepts a measured bias and full correction matrix. Identity correction is explicitly reported as `factory_only_magnetic_reference`, never as a completed hard/soft-iron calibration. A north-facing sample establishes world alignment but cannot determine magnetic bias or soft-iron distortion; those require diverse physical orientations. Until that calibration is complete, factory-only magnetic observations initialize the startup heading but do not continuously pull an already initialized gyro heading toward a potentially biased compass. Magnetic disturbance remains an accuracy limitation.

Host regression: `c++ -std=c++11 -Wall -Wextra -Werror -I overlay/include overlay/tests/ahrs_persistence.cpp -o /tmp/ahrs-persistence && /tmp/ahrs-persistence`. Covers CRC/version corruption, axis mapping, full3D recovery, off-power heading changes, IMU reconnect, rejected field observations and uploaded magnetic corrections.
